# 大模型开发实习招聘要求整理

## 1. 岗位总体定位

目前收集到的多份大模型开发实习 JD，整体指向的是：

> 大模型应用开发 + Agent/RAG 工程化 + AI 平台工具链 + LLMOps + 低代码/集成平台 + 后端服务开发 + 轻量级模型微调。

这类岗位不是单纯训练基础大模型，也不是传统后端开发，而是围绕已有大模型能力，将其接入真实业务、内部工具、文档系统、代码系统、低代码平台和企业应用平台中，形成可运行、可评估、可部署、可监控、可扩展的大模型应用。

核心目标：

- 让大模型具备多轮对话、智能问答、内容生成和业务流程自动化能力；
- 让大模型能够调用工具、访问知识库、连接数据库、执行代码和使用内部工具链；
- 通过 Agent、RAG、MCP、Workflow、LLMOps 等方式将模型能力落地到真实业务；
- 建设 AI 平台、低代码平台、集成平台和智能伙伴创建平台，提升研发效率和业务交付效率；
- 保障线上系统高可靠、低延迟、可扩展、可观测。

## 2. 岗位画像分类

### 2.1 大模型应用落地 / Agent / RAG / MCP

代表要求：

- 参与大模型研发阶段；
- 结合 AI Agent、RAG、MCP 实现大模型落地；
- 将数据库操作、联网搜索、代码执行、内部工具链调用等能力集成至模型；
- 配合业务部门进行智能体最佳实践；
- 设计高性能、可扩展的 AI 应用服务架构。

岗位侧重点：

> Agent 工具调用 + RAG 应用 + 业务流程自动化 + 后端服务部署。

### 2.2 大模型平台 / 工作流 / 智能体协作 / 微调强化学习

岗位侧重点：

> 大模型应用平台 + Agent/RAG 进阶 + 模型微调 + 平台基础设施。

- 基于 OpenAI API、LangChain、LLaMA.cpp 等开发原型应用；

- 参与轻量级大模型微调或提示工程优化；

岗位侧重点：

> 原型开发 + 提示工程 + 内部效率工具 + 文档和技术调研。

代表要求：

- 构建 LLMOps 全链路流程；
- 进行大模型应用评测；
- 建设监控告警；

- 推动 MCP 生态建设、工作流编排、代码生成工具；
- 构建高可靠、高扩展 AI 架构；
- 熟悉 Dify 等业界主流大模型开发框架。

岗位侧重点：

> 应用评测 + 线上监控 + 数据闭环 + RAG 优化 + 高可靠 AI 架构。

### 2.5 低代码平台 / 集成平台 / 服务端系统开发

代表要求：

- 面向低代码平台和大模型应用团队，参与飞书低代码平台、飞书智能伙伴创建平台等产品建设；
- 协助设计和开发无代码/低代码平台、大模型应用、集成平台等产品；
- 协助服务端系统技术方案设计、开发和系统维护；
- 参与高质量设计和编码，支持重点难点技术问题攻坚；
- 持续跟踪大模型、低代码领域最新技术趋势和研究成果，并推动前沿技术整合进项目方案；
- 熟悉 Go、Java 等后端开发语言，掌握协议、架构、存储、缓存、安全等后端技术。

岗位侧重点：

> 后端工程能力 + 低代码平台 + 集成平台 + 大模型应用产品化。

这类 JD 对大模型理解有要求，但更看重工程落地能力，尤其是服务端开发、架构设计、系统维护和产品工程化。

## 6. 推荐项目准备方向

### 6.1 项目一：RAG 知识库问答系统

目标：实现一个可上传文档、解析文档、建立索引、进行问答和引用溯源的系统。

建议功能：

- PDF / Markdown / TXT 文档解析；
- Chunk 切分；
- Embedding；
- Faiss 或 Milvus 检索；
- Rerank；
- 问答生成；
- 引用来源展示；
- FastAPI 后端；
- Streamlit 前端；
- Docker 一键启动。

能匹配的 JD 要求：RAG、LlamaIndex、LangChain、Dify、向量数据库、智能问答、工程部署。

---

### 6.2 项目二：AI Agent 工具调用平台

目标：实现一个能够调用多种工具的智能体系统。

- 数据库查询工具；

- Python 代码执行工具；
- 文件读取工具；
- 内部 API 调用工具；
- GitHub / GitLab 工具；
- MCP 工具接口。

建议模块：

- 任务规划；
- 多步推理；
- Tool Calling；

能匹配的 JD 要求：Agent、Tool Calling、MCP、内部工具链调用、代码执行、平台工具建设。

## 9. 简历表达模板

### 9.1 RAG 项目

- 基于 FastAPI、LangChain / LlamaIndex 和 Faiss / Milvus 构建 RAG 知识库问答系统，支持文档解析、向量检索、Rerank、答案生成与引用溯源。
- 设计 Chunk 切分、召回、重排序和上下文组装策略，构建评估集分析检索准确率和问答质量。

### 9.2 Agent 项目

- 构建支持 Tool Calling 的 AI Agent 原型，集成数据库查询、联网搜索、Python 代码执行和文件读取等工具能力，实现多步骤任务自动执行。
- 使用 LangGraph 设计工作流状态机，支持任务规划、记忆管理、工具调用失败重试、异常处理和执行日志追踪。

### 9.3 内部效率工具项目

- 基于 OpenAI API / 通义千问 API 和 Streamlit 开发内部效率助手，支持文档自动化、代码生成、需求分析和智能问答等功能。
- 编写技术文档和使用案例，支持团队成员快速复用大模型能力。

### 9.4 LLMOps 项目

- 为 RAG / Agent 应用构建自动化评测与监控链路，统计回答质量、引用正确率、延迟、错误率和 Token 成本，并支持 Prompt 版本对比。

### 9.5 微调项目

- 基于 HuggingFace Transformers、PEFT 和 PyTorch 完成 LoRA 微调实验，构造指令数据集并对比微调前后模型效果。

### 9.6 平台工程项目

- 设计大模型应用服务架构，使用 Docker 进行容器化部署，并通过日志、异常处理和模块化设计提升系统稳定性与可维护性。

### 9.7 低代码平台后端项目

- 设计并实现简化版低代码大模型应用平台后端，支持应用配置、Prompt 模板管理、模型调用配置、工具绑定、知识库绑定、调用日志和权限控制。
- 基于 Go / Java / FastAPI、关系型数据库和 Redis 设计服务端分层架构，覆盖接口设计、存储建模、缓存策略、权限校验和系统维护。
