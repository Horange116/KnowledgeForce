# 大模型开发实习招聘要求整理

## 1. 岗位总体定位

目前收集到的多份大模型开发实习 JD，整体指向的是：

> 大模型应用开发 + Agent/RAG 工程化 + AI 平台工具链 + LLMOps + 轻量级模型微调 + 后端服务部署。

这类岗位不是单纯训练基础大模型，也不是传统后端开发，而是围绕已有大模型能力，将其接入真实业务、内部工具、文档系统、代码系统和平台产品中，形成可运行、可评估、可部署、可监控的大模型应用。

核心目标可以概括为：

- 让大模型具备多轮对话能力；
- 让大模型能够调用工具；
- 让大模型能够基于企业文档和业务数据回答问题；
- 让大模型能够辅助代码生成、文档自动化、测试分析、需求分析；
- 让大模型应用能够被调试、评测、部署、监控和持续优化；
- 让企业内部业务流程逐步被 Agent / Workflow 自动化。

- 构建支持 Tool Calling 的 AI Agent 原型，集成数据库查询、联网搜索、Python 代码执行和文件读取等工具能力，实现多步骤任务自动执行。
- 使用 LangGraph 设计工作流状态机，支持任务规划、记忆管理、工具调用失败重试、异常处理和执行日志追踪。

### 9.3 内部效率工具项目

- 基于 OpenAI API / 通义千问 API 和 Streamlit 开发内部效率助手，支持文档自动化、代码生成、需求分析和智能问答等功能。
- 编写技术文档和使用案例，支持团队成员快速复用大模型能力。

### 9.4 LLMOps 项目

- 为 RAG / Agent 应用构建自动化评测与监控链路，统计回答质量、引用正确率、延迟、错误率和 Token 成本，并支持 Prompt 版本对比。

### 9.5 微调项目

- 基于 HuggingFace Transformers、PEFT 和 PyTorch 完成 LoRA 微调实验，构造指令数据集并对比微调前后模型效果。

### 9.6 平台工程项目

- 设计大模型应用服务架构，使用 Docker 进行容器化部署，并通过日志、异常处理和模块化设计提升系统稳定性与可维护性。
