# 大模型开发实习招聘要求整理

## 1. 岗位定位

该岗位属于**大模型应用开发 / AI Agent 工程化 / RAG 应用落地 / AI 平台建设**方向。

核心目标不是单纯训练基础大模型，而是围绕已有大语言模型，结合 AI Agent、RAG、MCP、工具调用、代码执行、联网搜索、数据库操作等能力，构建可在真实业务中使用的大模型应用系统。

可以理解为：

> 将大模型从“能对话”推进到“能调用工具、能处理业务流程、能稳定部署上线”的工程岗位。

---

## 2. 岗位职责拆解

### 2.1 大模型应用落地

主要工作内容：

- 参与大模型研发阶段的应用侧建设；
- 结合 AI Agent、RAG、MCP 等技术手段实现大模型落地；
- 建设大模型周边工具生态；
- 将外部能力集成到模型系统中，包括：
  - 数据库操作；
  - 联网搜索；
  - 代码执行；
  - 内部工具链调用；
  - 业务系统接口调用。

对应能力要求：

- 理解 LLM 的基本调用方式；
- 理解工具调用、函数调用、Agent 执行链路；
- 能将模型输出与真实工具/API连接起来；
- 能处理工具调用失败、权限、安全、异常恢复等问题；
- 能根据业务流程设计智能体应用。

---

### 2.2 智能体最佳实践支持

主要工作内容：

- 配合业务部门进行智能体工具落地；
- 根据不同业务场景设计合适的 Agent 流程；
- 将重复性流程、信息检索流程、知识问答流程、数据处理流程转化为 AI 应用。

对应能力要求：

- 能理解业务需求；
- 能将业务需求拆成 Agent 可执行的任务链；
- 能设计 Prompt、工具集合、状态管理和失败回退机制；
- 能评估 Agent 输出质量；
- 能持续优化应用效果。

---

### 2.3 软件平台建设

主要工作内容：

- 设计高性能、可扩展的 AI 应用服务架构；
- 保证生产环境高可用、低延迟；
- 支持大模型应用的服务化、部署、监控和迭代。

对应能力要求：

- 熟悉后端服务开发；
- 熟悉 API 服务设计；
- 熟悉并发、异步、队列、缓存等性能优化手段；
- 理解容器化部署与运维；
- 理解线上服务稳定性、日志、监控、错误处理。

---

## 3. 岗位要求拆解

### 3.1 编程能力

原始要求：

> 扎实的编程能力，熟悉 Python/C++

需要准备：

- Python 基础扎实；
- 熟悉常见后端开发框架，例如 FastAPI、Flask；
- 能编写清晰、可维护、模块化的工程代码；
- 熟悉异步编程、文件处理、数据库访问、API 调用；
- C++ 至少需要具备基础阅读和简单开发能力；
- 熟悉 Linux 命令行、Git、调试和日志分析。

重点优先级：

1. Python 工程能力；
2. FastAPI / 后端服务开发；
3. API 调用与工具封装；
4. 数据库操作；
5. C++ 基础。

---

### 3.2 大模型基础原理

原始要求：

> 熟悉主流大语言模型基本原理

需要准备：

- Transformer 基本结构；
- Attention 机制；
- Tokenizer；
- 预训练、SFT、RLHF / DPO 的基本概念；
- 推理过程与上下文窗口；
- Prompt Engineering；
- Function Calling / Tool Calling；
- Embedding；
- RAG 基本流程；
- 向量数据库与相似度检索；
- 模型幻觉、上下文污染、检索失败等常见问题。

该岗位更偏应用工程，因此不需要优先深入大模型底层训练细节，但需要能解释基本原理，并能把原理转化为工程设计。

---

### 3.3 Agent 开发能力

原始要求：

> 掌握智能体开发基本框架

需要准备：

- Agent 的基本组成：
  - LLM；
  - Tools；
  - Memory；
  - Planner；
  - Executor；
  - Reflection / Evaluation；
  - Workflow / State Machine。

- 熟悉至少一种 Agent 框架：
  - LangChain；
  - LangGraph；
  - AutoGen；
  - CrewAI；
  - LlamaIndex；
  - OpenAI Agents SDK。

- 能实现：

  - 多步骤任务执行；
  - RAG + Agent；
  - 数据库查询 Agent；
  - 代码执行 Agent；
  - Web Search Agent；
  - 多 Agent 协作原型。

---

### 3.4 RAG 能力

招聘描述中明确提到 RAG，因此需要重点准备。

需要掌握：

- Chunk 切分；
- Embedding；
- 向量检索；
- 重排序 Rerank；
- 上下文组装；
- 引用溯源；
- 检索评估；
- 问答质量评估；
- 知识库更新机制。

可以准备的项目方向：

- 企业知识库问答系统；
- 论文问答系统；
- 医疗器械审查文档问答系统；
- 多文档一致性检查系统；
- 法规 / 标准文件检索系统。

---

### 3.5 MCP 能力

招聘描述中提到 MCP，需要了解其定位。

MCP 可以理解为一种让大模型统一连接外部工具、数据源和服务的协议。岗位中提到 MCP，说明工作可能涉及：

- 将数据库、搜索、文件系统、业务系统封装为 MCP Server；
- 让 Agent 通过 MCP 调用外部能力；
- 管理工具权限、参数、返回结果；
- 统一内部工具链的模型调用方式。

需要准备：

- MCP 的基本概念；
- MCP Server / MCP Client；
- Tool 定义；
- Resource 定义；
- Prompt 定义；
- 如何把本地工具或业务 API 封装成模型可调用工具。

---

## 5. 对应项目准备方向

### 5.1 推荐项目一：RAG 知识库问答系统

目标：实现一个可上传文档、解析文档、建立向量索引、进行问答和引用溯源的系统。

应包含：

- 文档解析；
- 文本切分；
- Embedding；
- 向量数据库；
- Rerank；
- 检索增强生成；
- 答案引用；
- FastAPI 服务；
- Docker 部署。

适合体现：RAG、LLM 应用、后端服务、工程落地。

---

### 5.2 推荐项目二：AI Agent 工具调用平台

目标：实现一个能够调用多种工具的 Agent 系统。

可集成工具：

- 数据库查询工具；
- Web Search 工具；
- Python 代码执行工具；
- 文件读取工具；
- 内部 API 调用工具。

适合体现：Agent、Tool Calling、MCP、工具生态建设。

---

### 5.3 推荐项目三：面向企业流程的智能体系统

目标：将一个真实业务流程拆解为 Agent 可执行流程。

可选场景：

- 医疗器械审查资料自动检查；
- 多文档一致性检查；
- 项目管理 Agent；
- 文献阅读与实验复现 Agent；
- 数据分析报告生成 Agent。

适合体现：业务理解、Agent 流程设计、工程落地能力。
