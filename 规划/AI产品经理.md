# AI 产品经理岗位要求整理

## 1. 岗位定位

该岗位更准确地说是：

> AI Agent 产品经理 / AI 应用落地产品经理 / 业务流程智能化产品经理。

它不是传统意义上只写 PRD、画原型、跟需求的产品经理，也不是纯开发岗位，而是介于**业务理解、产品设计、AI Agent 方案设计、轻量开发和落地迭代**之间的复合型岗位。

核心目标是：

- 深入理解公司内部不同岗位的真实工作流程；
- 找到具体业务场景中的低效、重复、可自动化环节；
- 用 AI Agent、RAG、函数调用、工具链等方式把岗位功能智能化；
- 从需求理解到方案设计、开发落地、效果评估、持续迭代形成闭环；
- 让 AI 真正可用、好用，并能带来效率提升、成本降低和体验改善。

---

## 2. 岗位职责拆解

### 2.1 业务流程理解与痛点挖掘

原始要求：

> 深入理解公司各业务岗位、各场景的真实工作流程与痛点，用 AI Agent 实现岗位功能智能化、自动化。

需要具备的能力：

- 能访谈业务人员，理解他们每天真实在做什么；
- 能拆解岗位工作流，包括输入、处理过程、输出和协作对象；
- 能识别重复性、规则性、信息检索型、文档处理型、数据处理型任务；
- 能判断哪些环节适合 AI Agent 自动化，哪些环节必须保留人工确认；
- 能将模糊的业务痛点转化为可实现的 AI 产品需求。

典型问题：

- 这个岗位每天最耗时的任务是什么？
- 这个流程中哪些步骤是重复性的？
- 哪些步骤依赖文档、表格、系统查询或固定判断规则？
- 哪些任务可以交给 Agent 做初稿、初筛、初判？
- 哪些任务需要人工最终确认？

---

### 2.2 从需求到落地的全流程闭环

原始要求：

> 独立完成从业务需求理解 → 方案设计 → Agent 开发 → 落地使用 → 效果迭代的全流程闭环。

这说明岗位不是只做产品文档，而是要求具备端到端推进能力。

完整闭环包括：

1. 业务访谈；
2. 场景拆解；
3. 需求定义；
4. AI 能力边界判断；
5. Agent 流程设计；
6. 工具链设计；
7. Prompt / RAG / 函数调用方案设计；
8. 原型开发或协同开发；
9. 小范围试用；
10. 数据收集；
11. 效果评估；
12. 迭代优化。

需要重点准备：

- PRD 能力；
- 流程图能力；
- Agent 任务流设计；
- 基础 Python 开发；
- Prompt 调试；
- 用户反馈分析；
- 指标设计与效果评估。

---

### 2.3 AI 能力边界、交互逻辑与工具链定义

原始要求：

> 基于用户 / 岗位实际操作习惯，定义 AI 能力边界、交互逻辑与工具链，确保 AI 真正可用、好用。

需要理解：

AI 产品经理不能只追求“AI 能不能做”，而要判断：

- AI 适合做什么；
- AI 不适合做什么；
- 哪些步骤需要人工确认；
- 哪些工具必须接入；
- 用户应该如何与 Agent 交互；
- Agent 失败时如何兜底；
- 如何让用户信任 AI 的结果。

能力边界设计包括：

- 输入边界：用户可以输入什么；
- 任务边界：Agent 能处理哪些任务；
- 工具边界：Agent 可以调用哪些工具；
- 权限边界：Agent 可以访问哪些数据；
- 风险边界：哪些动作必须人工确认；
- 输出边界：结果需要什么格式、证据和解释。

---

### 2.4 技术能力转化为业务价值

原始要求：

> 快速学习大模型、提示词工程、RAG、函数调用、Agent 框架等技术，把技术能力转化为业务价值。

该岗位不一定要求成为深度算法工程师，但必须能理解 AI 技术的产品化用法。

需要掌握：

- 大模型基础原理；
- Prompt Engineering；
- RAG；
- Function Calling / Tool Calling；
- AI Agent 基本框架；
- 多轮对话；
- 工具调用失败处理；
- 知识库问答；
- 轻量级 Python 开发与调试。

关键是能回答：

- 这个业务场景应该用 Prompt、RAG、Agent，还是普通规则系统？
- 这个功能是否需要接数据库、知识库或业务系统？
- 这个 Agent 的工具链应该包含哪些能力？
- 这个方案带来的效率提升如何衡量？

---

### 2.5 使用效果跟踪与迭代优化

原始要求：

> 持续跟踪 AI 应用使用效果，用数据和反馈迭代优化，提升效率、降低成本、改善体验。

需要建立指标意识。

常见指标：

- 使用人数；
- 使用频次；
- 任务完成率；
- 采纳率；
- 人工修改率；
- 平均处理时长；
- 节省时间；
- 错误率；
- 用户满意度；
- Token 成本；
- 工具调用成功率；
- 回答命中率。

需要能做：

- 收集用户反馈；
- 分析失败案例；
- 归类问题原因；
- 优化 Prompt、知识库、工具链或交互流程；
- 形成迭代记录。

## 3. 岗位要求拆解

### 3.1 学历与专业

要求：

- 本科及以上学历；
- 计算机、软件、数据、自动化等相关专业优先。

说明：

该岗位欢迎技术背景，因为需要理解 Agent、RAG、函数调用和基础开发。但产品意识和业务理解同样重要。

---

### 3.2 AI 热情与学习能力

要求：

- 对 AI 有极强热情与好奇心；
- 聪明；
- 学习能力极强；
- 自驱力强。

实际含义：

- 能快速学习新工具；
- 能主动尝试新的 Agent / RAG / Prompt 方案；
- 能自己查资料、做 Demo、验证效果；
- 不依赖别人给完整指令。

可以体现方式：

- 有 RAG 项目；
- 有 Prompt 优化案例；
- 有自动化工具项目；
- 有持续学习记录或技术总结。

---

### 3.3 基础编程能力

要求：

- 具备基础编程能力；
- Python 优先；
- 逻辑清晰；
- 能快速上手开发与调试。

需要准备：

- Python 基础；

- 文件读写；

---

### 3.4 业务思维与产品意识

要求：

- 能站在用户 / 岗位角度思考问题；
- 理解场景；
- 懂需求；
- 懂落地。

需要准备：

- 用户访谈；
- 需求分析；
- 场景拆解；
- 用户旅程图；
- 业务流程图；
- PRD；
- 原型图；
- MVP 思维；
- 数据指标设计。

核心判断标准：

> 不是“我会用 AI 做什么”，而是“这个岗位的什么问题值得用 AI 解决，以及怎么让用户真的用起来”。

---

### 3.5 沟通与需求翻译能力

要求：

- 沟通表达顺畅；
- 能与非技术岗位对齐需求；
- 能把业务语言翻译成技术方案。

典型转化方式：

- 业务说：“这个表每次整理很麻烦。”
- 产品要转化为：“需要一个 Agent，支持上传表格，自动提取字段、校验缺失值、生成汇总报告，并在关键异常处要求人工确认。”

需要输出：

- 业务流程图；
- 需求文档；
- Agent 流程图；
- 工具清单；
- 输入输出格式；
- 验收标准；
- 迭代计划。

## 5. 推荐项目方向

### 5.1 岗位流程自动化 Agent

目标：选择一个真实岗位，拆解其工作流程，并用 Agent 自动化其中一部分。

可选岗位：

- 招聘专员；
- 客服；
- 销售；
- 运营；
- 项目经理；
- 审核人员；
- 文档管理员。

建议功能：

- 输入任务；
- 分析任务类型；
- 调用知识库；
- 调用工具；
- 生成结果；
- 人工确认；
- 记录反馈；
- 迭代优化。

---

### 5.2 企业知识库问答产品

目标：构建一个面向内部员工的知识库问答系统。

建议功能：

- 文档上传；
- 文档解析；
- Chunk 切分；
- 向量检索；
- RAG 问答；
- 引用来源；
- 用户反馈；
- 问题分析报表。

产品侧重点：

- 用户为什么需要它；
- 哪些场景会用；
- 准确率如何评估；
- 错误答案如何处理；
- 如何推动内部使用。

---

### 5.3 AI 需求分析助手

目标：帮助产品经理或业务人员把模糊需求整理成结构化需求文档。

建议功能：

- 输入业务描述；
- 自动提取用户、场景、目标、痛点；
- 生成用户故事；
- 生成流程图描述；
- 生成验收标准；
- 生成风险点；
- 支持人工修改。

能体现：业务理解、产品意识、Prompt 设计、Agent 流程设计。

---

### 5.4 AI 工作流配置平台原型

目标：设计一个让非技术人员配置 AI Agent 工作流的产品原型。

建议模块：

- Agent 创建；
- Prompt 配置；
- 工具选择；
- 知识库绑定；
- 触发条件；
- 人工确认节点；
- 运行日志；
- 效果反馈。

能体现：AI 产品设计、低代码思维、Agent 产品化能力。

## 8. 面试需要准备的问题

### AI 产品理解

- AI 产品经理和传统产品经理有什么不同？
- 什么场景适合用 AI Agent？
- 如何判断一个业务流程是否适合 AI 自动化？
- 如何定义 AI 能力边界？
- 如何让用户信任 AI 输出？

### Agent 方向

- Agent 和 Chatbot 的区别是什么？
- 一个 Agent 通常由哪些模块组成？
- 工具调用失败怎么办？
- 哪些动作必须设置人工确认？
- 如何设计 Agent 的记忆机制？

### RAG 方向

- RAG 解决什么问题？
- 知识库问答为什么需要引用来源？
- 如何评估 RAG 问答效果？
- 文档切分会影响什么？

### 产品落地方向

- 如何从业务访谈中提炼需求？
- 如何把业务语言翻译成技术方案？
- 如何设计 MVP？
- 如何衡量 AI Agent 的效果？
- 如果用户不愿意使用 AI 工具怎么办？
