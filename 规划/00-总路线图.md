# AI Agent 职业路线总览

## 1. 总体定位

当前最适合的职业定位：

> AI Agent 应用工程师，主攻企业流程智能化、RAG、工具调用、Agent Workflow 与评测闭环；中期向 Agent Runtime / AI Infra 延伸。

这一路线不是泛泛的“大模型开发”，也不是纯产品经理或纯算法研究岗，而是围绕真实业务流程，把大模型能力转化为可运行、可评测、可部署、可迭代的 Agent 系统。

---

## 2. 重新划分后的四个方向

### 方向一：Agent 应用工程方向

主方向。

重点是把 Agent 做成真实业务系统，覆盖 RAG、Tool Calling、Prompt 编排、业务流程拆解、FastAPI 服务化、结构化输出、Trace、Eval 和简单前端。

典型岗位：

- AI Agent 开发工程师
- 大模型应用工程师
- RAG / Deep Research 工程师
- 智能客服 Agent 工程师
- 企业知识库 / 文档审查 Agent 工程师
- 行业运营 Agent 工程师

适合短期主攻。

---

### 方向二：Agent Runtime 与 AI Infra 方向

中长期技术升级方向。

重点是支撑 Agent 稳定运行的底层系统，包括 Agent Loop、Context 管理、Memory、工具调度、Hooks、流式输出、多 Agent 并发、可观测、高可用、云原生部署和资源调度。

典型岗位：

- Agent Runtime 工程师
- Agent Framework 工程师
- Agent Infra 工程师
- AI 原生应用平台工程师
- 多 Agent 框架工程师
- 云原生 Agent 平台工程师

适合作为应用工程之后的进阶路线。

---

### 方向三：大模型后训练与 Agent 算法优化方向

高门槛算法研究方向。

重点是通过 SFT、DPO、RLHF、PPO、RLAIF、Agentic RL、Reward、Trajectory、模型评测和数据飞轮提升模型与 Agent 的能力上限。

典型岗位：

- 大模型算法工程师
- Agent 算法工程师
- Post-training 工程师
- RL / Reward 工程师
- Agentic RL 研究工程师
- 大模型能力优化工程师

不作为短期主攻，但需要理解基本概念，方便后续升级。

---

### 方向四：AI 产品与业务流程智能化方向

辅助方向。

重点是理解真实企业流程，判断哪些环节适合 Agent 化，设计 AI 产品、Workflow、人工确认节点、指标体系、评测集和数据闭环。

典型岗位：

- AI 产品经理
- Agent 产品经理
- AI 应用平台产品经理
- 企业流程智能化产品经理
- AI 工作流产品经理
- 大模型评测 / 数据产品经理

这不是当前主投方向，但对做企业流程 Agent 很重要。

---

## 3. 推荐优先级

### 第一优先级

- Agent 应用工程方向
- RAG / Deep Research / 企业知识库 / 文档审查
- 行业 Agent / 业务流程智能化

### 第二优先级

- Agent Runtime / Framework
- Agent Eval / 测试质量
- AI Coding / 工程研发 Agent

### 第三优先级

- 大模型后训练
- Agentic RL
- 多模态 Agent
- AI Infra / 推理框架 / 云原生平台

---

## 4. 当前最推荐项目

主项目固定为：

> 企业文档审查 Agent：基于 RAG、工具调用和评测 Harness 的多文档一致性分析系统。

项目应覆盖：

- 文档解析
- Chunk 切分
- Embedding 与向量检索
- RAG 问答
- Tool Calling
- LangGraph Workflow
- 结构化输出
- 引用检查
- Trace 日志
- Eval Harness
- FastAPI 服务
- Docker 部署
- 简单前端
